# Hospital Queue Management System Architecture

## Project Overview

This project is a Hospital Discovery, Appointment Booking, and Real-Time Patient Queue Management System.

The goal is to allow users to:

- Search hospitals by city
- View hospital details
- Book appointments
- Join a live patient queue
- Track queue status in real time

---
